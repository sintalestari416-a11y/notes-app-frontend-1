# Express Web Server 🚀

Proyek ini adalah web server sederhana yang dibangun menggunakan **Node.js** dan framework **Express**. Dibuat sebagai bagian dari modul latihan "Belajar Back-End Pemula dengan JavaScript" di Dicoding.

## ✨ Fitur
- Menggunakan **ES6 Modules** (`import`/`export`).
- Routing dasar (Homepage, About, dll).
- Implementasi **Path Parameters** (contoh: `/hello/:name`).
- Penanganan Method HTTP yang tidak diizinkan (405).
- Custom 404 Page (Halaman tidak ditemukan).
